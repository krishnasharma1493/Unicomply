# Source of `AICTE_Approved_Colleges_Master.xlsx`

AICTE's Approved Institutes list for academic year 2024-25, as published by AICTE's public dashboard
(https://facilities.aicte-india.org/dashboard/pages/angulardashboard.php#!/approved) and saved to a spreadsheet by a public scraper:

- Repository: https://github.com/artsin124/SIH-Apaar, file `AICTE_Approved_Colleges_Master.xlsx` (commit c7aac45ad95ce672a1df2158e96621050513a21b)
- Scraped: 2026-10-23, 13,085 institutions, 36 states and union territories
- SHA-256 of the file as committed here: 94259ae96a8835a64d05d713a19d7497676ade83b3b60ff772639d7e83d79d87

Columns: AICTE ID (the Permanent ID), name, address, district, institution type (ownership), women, minority, and links to course and faculty details. There is no state column; see `../README.md`.
